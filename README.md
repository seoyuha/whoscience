# 누가 그런 거지? 과학 탐정단

교실 TV 1대 + 학생 태블릿으로 하는 4~30명 추리 놀이 (3학년 과학 복습판). 가입·로그인 없음, 판 기록 저장 없음.
영어판 whomess를 3학년 2학기 과학(2단원 지구와 바다 · 3단원 소리의 성질)용으로 바꿨어요.

## 교사 비밀번호
TV에서 방을 만들 때 교사 비밀번호를 물어요(브라우저마다 한 번만 입력하면 저장).
비밀번호는 선생님이 정한 교사 비밀번호예요 (과학 정원 지키기·점프맵과 같아요). 코드에는 해시값만 들어 있어요.

## 올리기 (Render)
1. 이 폴더를 GitHub 새 저장소에 올려요 (node_modules 제외).
2. Render → New → Web Service → 저장소 연결
   - Build Command: `npm install`
   - Start Command: `npm start`
   - 무료 요금제 가능
3. 주소가 나오면 TV에서 그 주소로 들어가 **방 만들기 (TV)**.

## 과학 문제 (TV 대기실 설정)
TV 대기실 설정의 **과학 문제** 칸에서 골라요.
- **끔** : 문제 없이 원래 방식 (하기 버튼을 꾹 누르면 심부름 끝)
- **2단원 / 3단원 / 섞기** : 하기를 꾹 누른 뒤 과학 문제(3지선다)를 맞혀야 심부름 끝. 틀리면 정답과 해설이 잠깐 보인 뒤 다른 문제를 풀어요.
- **직접** : `문제 | 정답 | 오답 | 오답 | 해설` 한 줄씩 붙여 넣기 (TV 브라우저에 저장됨)

기본 문제(2단원 69문제·3단원 71문제)는 `public/questions.js`에서 고칠 수 있어요.

## 학교 (15곳 + 체육관)
위: 3학년 1반 · 3학년 2반 · 3학년 3반 · 도서실 · 과학실 · 컴퓨터실 · 화장실
아래: 교무실(비상벨) · 보건실 · 3학년 4반 · 급식실 · 3학년 5반 · 3학년 6반 · 3학년 7반
가운데 긴 복도(서관·동관, 차단기), 동쪽 끝 체육관. (영어판의 방송실·미술실·음악실·시청각실을 교실로 바꿨어요 — `tools/make7/convert.py`)

## 더 재미있게 (TV 대기실 설정)
- **단서 카드** (기본 켬): 모두의 심부름이 25·50·75%가 될 때마다 장난꾸러기 겉모습 단서가 나와요. 안경·모자·리본·머리색·옷 색만 쓰고 피부색은 쓰지 않아요.
- **특별 규칙** (기본 끔): 장난꾸러기 팀이 한 번 정전(20초 동안 도우미 시야 2칸, 복도 차단기를 두 명이 고치면 바로 복구) / 도우미 중 탐정(친구 1명의 최근 방 3곳 조사)·사진부(그 방에 있던 사람을 다음 회의 때 공개)·반장(투표 2표).
- **내가 본 것 기록장**: 회의 때 태블릿에 본 친구·장소·시각이 자동으로 정리돼요.
- **판 끝 다시 보기**: TV에서 장난꾸러기의 움직임과 장난을 시간순으로 재생해요(판 끝 공개가 켜져 있을 때).
- **인트로 영상**: 첫 화면(index.html)이 열리면 인트로 영상(assets/intro.mp4)이 먼저 나와요. 끝나면 저절로, 또는 화면을 누르거나 '건너뛰기'로 첫 화면으로 넘어가요. 같은 탭에서는 한 번만 나와요. '🔊 소리 켜기'를 누르면 소리가 나요(처음엔 자동재생 규칙 때문에 무음). 영상을 바꾸려면 assets/intro.mp4만 갈아 끼우면 돼요.
- **이번 판 열심왕**: 심부름 10점 · 치우기 15점 · 회의 열기 10점 · 장난 20점(판 끝 공개가 켜져 있을 때만)으로 활동 점수를 매겨, 판 끝 TV에 1~5위를 보여줘요. 학생 태블릿에는 자기 기록과 등수가 나와요. 판 끝 공개를 끄면 장난 점수·장난꾸러기 표시는 빠져요(누가 장난꾸러기였는지 드러나지 않게).
- **선생님 이벤트** (TV 놀이 화면의 버튼): 📢 긴급 방송(무작위 방에 특별 심부름, 60초 안에 해결하면 막대 +3%, 판마다 3번) · 🍚 급식 시간(20초 안에 급식실로, 모인 사람 수×0.5% 보너스, 1번) · 🔍 불시 점검(30초 동안 장난 금지, 2번).
- **분실물 줍기**: 복도에 가끔 동전·지우개·실내화가 떨어져요(최대 2개, 70초 뒤 사라짐). 밟으면 자동으로 줍고(2개까지), 교무실 분실물 보관함에 '하기'로 맡기면 막대 +1(도우미), 열심왕 +5점.
- **발자국 단서** (기본 끔, 대기실 설정 '발자국'): 장난이 드러나면 범인이 떠난 방향으로 발자국이 12초 동안 보여요. 추리가 쉬워지니 처음 몇 판이나 저학년 수준에 맞출 때 켜세요.
- **학급 대항 기록**: TV 대기실 아래 '우리 반'(8반·9반·10반, 바꿀 수 있음)을 고르고 하면 판이 끝날 때 반 기록에 더해져요. 🏆 학급 기록 버튼으로 순위표(점수 = 도우미 승리×10 + 찾은 장난꾸러기×3 + 평균 심부름%÷10)를 봐요. 기록은 TV 컴퓨터 브라우저에만 저장되고 학생 별명은 저장하지 않아요.
- **연출**: 1분 남으면 경고, 마지막 10초 째깍 소리, 어질러짐 4곳이면 TV 빨간 깜빡임, 이긴 뒤 캐릭터 달리기.

## 글꼴
픽셀 글꼴 갈무리(Galmuri, OFL)를 public/assets/fonts/에 직접 넣어서 구글 글꼴이 막힌 학교 망에서도 똑같이 보여요.

## 그림 바꾸기
선생님 그림 묶음을 `extra/` (effects/ · new/ · ui/)에 넣고 `tools/`의 build_map.py·mess.py를 다시 돌리면, 같은 이름의 그림이 자동으로 바뀌어요.

## 밸런스 (자동, server.js의 IMP_TABLE·PER_HELPER)
학생 수 × 놀이 시간으로 저절로 정해져요. TV 대기실 아래 '밸런스 표' 버튼에 전체 표가 있어요.
- 장난꾸러기 수 — 5분: 4명부터 1, 15명부터 2 · 8분: 4명부터 1, 13명부터 2, 23명부터 3 · 10분: 4명부터 1, 12명부터 2, 21명부터 3 (3학년이라 영어판보다 적게)
- 도우미 1명당 심부름 — 5분 8개 · 8분 12개 · 10분 15개 (과학 문제 켜면 6·9·11개)
- 장난 쉬는 시간 — 30초 + 장난꾸러기 한 명 늘 때마다 5초
- 설정에서 장난꾸러기 수를 직접 정하면 그 수를 쓰고, 심부름 양과 쉬는 시간은 거기에 맞춰 다시 계산해요.

## 파일
- `server.js` 서버 (방·역할·심부름·장난·회의·투표·승패)
- `public/index.html`, `public/game.js` 학생 태블릿 / 혼자 연습하기
- `public/tv.html` 교실 TV
- `public/assets/` 맵·캐릭터·어질러짐 그림 (`tools/`의 파이썬으로 만듦)

## 시험용
`FAST=1 npm start` 로 켜면 모든 시간이 짧아져요(장난 3~4초 뒤 드러남, 회의 6초).
